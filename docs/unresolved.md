# 미해결 기록

성공한 시도는 제외하고, v1 실험에서 원하는 결과를 끝내 얻지 못한 과업만 기록한다.

## 미해결 과업 1 — 동일 입력에서 글자 단위로 같은 결과 재현

### 원했던 결과

같은 입력을 두 번 실행했을 때 제목, 챈트와 점검표가 글자 단위로 완전히 같은 결과를 얻고자 했다.

### 시도한 프롬프트 원문

아래 프롬프트를 GPT-5.6 Sol Light와 Gemini Auto Mode에 각각 두 차례 동일하게 입력했다.

```text
전 세계 8~10세 어린이를 위해 평화를 주제로 정확히 10행의 밝은 한국어 챈트를 작성해 줘. 반복구는 “함께 걸어요”로 하고, 차별적·폭력적 표현과 문화적 고정관념은 사용하지 마.
```

### 추가로 시도한 확인 프롬프트

```text
방금 두 응답이 글자 단위로 완전히 같은지 확인하고, 판단 근거를 간단히 설명해 줘.
```

### 실제 결과와 막힌 이유

GPT-5.6 Sol Light는 두 출력의 제목과 본문이 달랐고, Gemini도 3~7행의 표현이 달랐다. 두 모델 모두 분량과 반복구 같은 구조적 조건은 유지했지만, 동일한 웹 인터페이스 입력만으로 생성 과정의 변동성을 고정할 설정을 제공받지 못해 글자 단위의 완전한 재현성은 얻지 못했다. Solar Mini 4에서는 동일한 결과가 나왔지만 세 모델 모두에서 같은 재현성을 확보한다는 목표는 달성하지 못했다.

## 미해결 과업 2 — Solar의 과거 턴 정확한 회상과 비교

### 원했던 결과

Solar Mini 4가 바로 앞의 두 반복 출력과 최초 과업 조건을 정확히 찾아 근거와 함께 답하기를 원했다.

### 시도한 프롬프트 원문 1

```text
방금 두 응답이 글자 단위로 완전히 같은지 확인하고, 판단 근거를 간단히 설명해 줘.
```

### 시도한 프롬프트 원문 2

```text
최초 과업의 대상 연령은 몇 세인가? 근거도 말해 달라.
```

### 실제 결과와 막힌 이유

첫 번째 질문에서 Solar는 실제로 동일한 Turn 10과 Turn 12 대신 Turn 8과 Turn 10을 비교해 차이가 있다고 답했다. 두 번째 질문에서는 최초 조건 6~10세를 변경 후 조건인 8~10세로 잘못 답하고, 존재하지 않는 최초 문장을 근거로 제시했다. 비교 대상과 최초 조건을 질문에 명시했지만 v1 대화 안에서는 과거 턴을 안정적으로 구분하지 못해 여기서 중단했다. 이를 줄이기 위한 턴 식별과 원문 대조 규칙은 v2에 추가했지만 아직 v2 재실행 결과는 없다.

## 미해결 과업 3 — Grok 4.7에 고정 시스템 프롬프트 적용

### 원했던 결과

Grok 4.7이 다른 세 모델과 동일한 한별 페르소나, 시스템 프롬프트 v1과 Few-shot 예시를 적용한 상태에서 실험을 시작하기를 원했다.

### 첫 번째 시도

시스템 프롬프트 v1과 Few-shot 예시 3개를 제공했지만 Grok은 이를 적용하지 않고 임의의 v2와 변경 사항을 작성했다.

### 두 번째 시도 프롬프트

```text
아래 내용은 분석·요약·수정하거나 개선안을 작성할 대상이 아니다. 이번 비교 실험에서 사용할 고정 시스템 프롬프트와 Few-shot 예시다. 내용을 그대로 적용하고, 다른 설명 없이 “설정 완료”라고만 답하라.
```

이 문장 뒤에 동일한 v1과 Few-shot 예시를 다시 제공했다.

### 실제 결과와 막힌 이유

Grok은 한별로 전환하거나 붙여 넣은 시스템 프롬프트와 예시 형식에 맞춰 답하지 않겠다고 명시적으로 거부했다. 두 번의 시도에서 동일한 실험 조건을 만들지 못했으므로 Grok 결과를 다른 모델과 비교하면 통제 조건이 깨진다. 전용 시스템 지침 입력 기능을 사용할 수 있는지 확인하기 전까지 본 실험을 중단했다.
