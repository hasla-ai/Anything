# LLM 모델 비교와 선정 보고서

## 1. 과업 선정과 정의

### 반복 과업

동일한 조건을 세 종류 이상의 LLM에 제시하고, 전 세계 어린이를 위한 한국어 챈트를 생성한 뒤 같은 기준으로 결과를 비교한다.

### 타겟 사용자

주요 사용자는 6~10세 어린이이며, 보조 사용자는 수업이나 활동에서 챈트를 활용하는 보호자와 교사, 그리고 LLM 결과를 비교하는 연구자다.

### 업무 문제

LLM마다 아동에게 적합한 어휘, 반복구, 리듬, 포용적 표현을 처리하는 방식이 다르기 때문에 동일한 입력과 평가 기준을 사용해 가장 적합한 모델을 선정해야 한다.

### 입력 데이터 형태

주제, 대상 연령, 핵심 메시지, 분위기, 분량, 반복구, 필수 내용과 금지 내용을 포함한 구조화된 텍스트 프롬프트를 입력한다.

### 출력 규격

- 쉬운 한국어로 작성한 제목과 8~12행의 창작 챈트
- 어린이가 따라 하기 쉬운 반복구와 일정한 리듬
- 다양성, 우정, 평화의 메시지
- 차별적·폭력적 표현 및 특정 문화에 대한 고정관념 배제
- 대상 연령, 반복구, 메시지, 안전성에 대한 간단한 조건 점검표

## 2. 공통 과업 프롬프트

아래 프롬프트를 세 모델에 수정 없이 동일하게 입력한다.

```text
전 세계 6~10세 어린이를 위한 한국어 챈트를 작성해 주세요.

- 주제: 함께 살아가는 우리
- 핵심 메시지: 서로 다른 모습과 문화를 존중하고 평화롭게 지내자.
- 분위기: 밝고 힘차게
- 분량: 8~12행
- 필수 조건: 쉬운 단어, 반복구, 일정한 리듬
- 금지 조건: 차별적 표현, 폭력적 표현, 특정 문화를 일반화하는 표현

제목과 챈트를 제시한 뒤, 각 조건의 충족 여부를 간단히 표시해 주세요.
```

## 5. 비교 기준과 채점 방식

각 기준은 5점 만점으로 평가하며, 점수 옆에 출력 원문을 근거로 한 설명을 기록한다.

| 평가 기준 | 평가 내용 |
|---|---|
| 지시 준수도 | 대상 연령, 언어, 분량, 주제와 출력 형식을 지켰는가 |
| 아동 적합성 | 6~10세 어린이가 쉽게 이해하고 따라 할 수 있는가 |
| 리듬과 반복성 | 챈트에 적합한 리듬과 명확한 반복구가 있는가 |
| 메시지 전달력 | 다양성, 우정, 평화의 메시지가 명확한가 |
| 창의성 | 표현과 구성이 흥미롭고 독창적인가 |
| 안전성과 포용성 | 차별·폭력·고정관념 없이 다양한 어린이를 포용하는가 |

점수 기준은 `5점=매우 우수`, `4점=우수`, `3점=보통`, `2점=미흡`, `1점=매우 미흡`으로 통일한다.

### 선정 결론
